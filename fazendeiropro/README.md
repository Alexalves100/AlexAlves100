# FazendeiroPRO - Screenshots Placeholder

Este diretório deve conter as imagens (screenshots) do projeto FazendeiroPRO para o README principal.

## Imagens Necessárias

1. `dashboard.png` - Dashboard executivo com KPIs agropecuários
2. `pastos_mapa.png` - Mapa de pastos com Leaflet (UA/ha, rotação)
3. `ia_sql.png` - Demonstração do Text-to-SQL (IA Generativa)
4. `pwa_mobile.png` - PWA rodando no mobile (offline-first)

## Como Obter

1. Execute o projeto localmente (`cd frontend && npm run dev`)
2. Navegue pelas telas principais
3. Capture screenshots (Win+Shift+S no Windows)
4. Salve neste diretório com os nomes acima
5. As imagens serão referenciadas automaticamente no README.md principal

## Dimensões Recomendadas
- Largura: 800-1200px
- Formato: PNG (preferencial) ou JPG
- Proporção: 16:9 ou 4:3
